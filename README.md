# Penny Log

A free, open-source expense tracker that runs in your browser. No account, no server, no ads.

**Live app:** https://sanjayspear.github.io/penny-log/

## Features

- Add, edit and delete daily expenses
- Monthly totals with a comparison to the previous month
- Spending by category and day-by-day charts
- Monthly budgets per category with progress bars
- Recurring expenses (rent, subscriptions, bills) added automatically each month
- Export your expenses as CSV
- Light and dark mode that follows your device
- Built-in usage guide

## How to use

Open the live app and press the **Guide** button at the top for step-by-step help.

## Your data

Your expenses are stored only in your own browser (local storage). Nothing is sent anywhere. Clearing your browser's site data erases them, so use **Export** to keep a CSV backup.

## Run it yourself

Download `index.html` and open it in any browser. There is nothing to install.

## Host your own copy

Fork this repository, then open Settings > Pages and deploy from the `main` branch.
